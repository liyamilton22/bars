# Отчёт по ЛР6

Студентка: Газизьянова Лия, группа ТРИС-3-23

## Цель
Отделить интерфейс от источника данных: список и форма вызывают функции API-модуля (`getTickets`, `createTicket`), показывают состояния загрузки и три разных отказа, защищены от двойной отправки.

## Состояния списка

| Состояние | Как получено | Что видно |
|---|---|---|
| loading | открытие страницы | «Загрузка…» |
| data | ответ 200, массив не пуст | таблица заявок |
| empty | ответ 200, массив пуст | «Записей пока нет» |
| error | ответ 500 | сообщение и кнопка «Повторить» |

## Отказы

| Отказ | Как воспроизведён | Ветка | Текст человеку |
|---|---|---|---|
| 400 | флаг mock force400 | !response.ok, status 400 | Проверьте поля |
| 500 | флаг mock force500 | !response.ok, status 500 | Сервер не смог обработать запрос |
| Нет связи | USE_MOCK = false, сервер не запущен | catch, ответа нет | Нет связи с сервером |

## Дополнительно
- Двойной клик создаёт одну запись: ранний `return` и `:disabled="isSubmitting"`.
- `id`, `number`, `status` приходят из ответа, форма их не вычисляет.
- Адрес API хранится в `.env` (`VITE_API_BASE_URL=http://localhost:5000`), в Git лежит только `.env.example`.
