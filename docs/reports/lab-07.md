# Отчёт по ЛР7

Студентка: Газизьянова Лия, группа ТРИС-3-23

## Цель
Поднять каркас ASP.NET Core Web API на порту 5000 со Swagger и служебными адресами `/health` и `/info`.

## Что сделано
- проект создан в `backend/` (ASP.NET Core Web API с контроллерами);
- HTTP-порт 5000 задан в `Properties/launchSettings.json`;
- подключён Swagger (только в Development);
- добавлены `GET /health` и `GET /info`;
- созданы папки Controllers, Services, Models, Data;
- сервис `TicketService` зарегистрирован через DI.

## Проверка адресов

| Адрес | Результат |
|---|---|
| http://localhost:5000/swagger | открывается страница Swagger |
| http://localhost:5000/health | 200, `ok` |
| http://localhost:5000/info | имя приложения, среда Development, версия ЛР7 |

## Почему DI
Сервис зарегистрирован через DI, чтобы контроллер не создавал реализацию через `new`. Реализацию хранения можно заменить (например, список в памяти на PostgreSQL), не переписывая контроллер.
