## 1. Название проекта и организация

**Название проекта:** Информационная система мониторинга сроков и этапов выполнения работ при реконструкции сетевых объектов.

**Организация:** АО «Сетевая компания».

---

## 2. Главная сущность и справочник

**Главная сущность:** заявка на контроль этапа реконструкции.

**Справочник:** сетевые объекты.

Каждая заявка связана с конкретным сетевым объектом через числовое поле `siteId`.

---

## 3. Роли и права

| Действие | Диспетчер | Исполнитель |
|---|---|---|
| Войти в систему | Да | Да |
| Просматривать заявки | Да | Да |
| Создавать заявку | Да | Нет |
| Выбирать сетевой объект | Да | Нет |
| Назначать исполнителя | Да | Нет |
| Просматривать назначенные ему заявки | Да | Да |
| Переводить свою заявку в работу | Нет | Да |
| Закрывать свою заявку | Нет | Да |
| Отменять заявку | Да | Нет |

---

## 4. Основной сценарий

Диспетчер создаёт заявку на контроль этапа реконструкции, указывает сетевой объект и описание работы, назначает исполнителя, после чего исполнитель переводит назначенную ему заявку в работу и завершает её.

---

## 5. Соответствие требованиям курса

| Требование курса | Реализация в проекте |
|---|---|
| Главная запись | Заявка на контроль этапа реконструкции |
| Справочник | Сетевые объекты |
| Создание записи | Диспетчер создаёт заявку |

| Человеческий номер | У каждой заявки есть номер |
| Технологии | Vue 3 + ASP.NET Core + PostgreSQL |

---

## 6. Что не входит в реализацию в рамках семестра

В рамках семестра реализуется базовая версия системы: авторизация, роли пользователей, создание и просмотр заявок, выбор сетевого объекта, назначение исполнителя и изменение статусов.

Вне семестровой реализации остаются сложная аналитика, мобильное приложение, интеграция с внешними информационными системами, BIM/GIS-модули, автоматические уведомления и расширенная отчётность.

---

## 7. Резерв для развития ВКР

В дальнейшем проект может быть расширен в рамках выпускной квалификационной работы:

1. Учёт плановых и фактических сроков выполнения этапов реконструкции.
2. Интеграция с внешними информационными системами организации.
3. Добавление GIS-модуля для отображения сетевых объектов на карте.
4. Формирование аналитических отчётов по срокам и выполнению работ.
5. Добавление системы уведомлений о приближении или нарушении сроков.
6. Поддержка большого количества пользователей и заявок.

---

## 8. Почему тема не является копией проекта одногруппника

Проект посвящён мониторингу сроков и этапов реконструкции сетевых объектов АО «Сетевая компания». Главной сущностью являются заявки на контроль этапов реконструкции, а основными ролями являются диспетчер и исполнитель.
